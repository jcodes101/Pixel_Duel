# Character artwork credits

The character sprite sheets in the six class folders come from the free CraftPix packs listed below. Their original variant directory names are preserved in each class folder. The six source packs contain the same 35-byte `Licens.txt`/`License.txt` notice linking to CraftPix's license; one original copy is preserved here as `CraftPix-Licens.txt`.

- Ninja: https://dev.craftpix.net/freebies/free-ninja-sprite-sheets-pixel-art/
- Samurai: https://craftpix.net/freebies/free-samurai-pixel-art-sprite-sheets/
- Knight: https://craftpix.net/freebies/free-knight-character-sprites-pixel-art/
- Wizard: https://craftpix.net/freebies/free-wizard-sprite-sheets-pixel-art/
- Skeleton: https://dev.craftpix.net/freebies/free-skeleton-pixel-art-sprite-sheets/
- Yokai: https://craftpix.net/freebies/free-yokai-pixel-art-character-sprites/

The packs' license permits use in personal and commercial games. Attribution is appreciated but not required. The artwork remains part of this game and is not offered as a standalone asset download.
